# 🤖 MAME AI - Smart AI Assistant

Your personal AI assistant powered by Google Gemini 2.5 Flash, built with Python and Streamlit.

## 🚀 Features
- Chat with Gemini 2.5 Flash AI
- Clean and simple chat interface
- Conversation memory (remembers chat history)
- Error handling for API issues

## 🛠️ Tech Stack
- Python
- Streamlit
- Google Gemini API
- Requests library

## ⚙️ Installation & Setup

### Step 1 — Clone the repository
git clone https://github.com/adhiv367/ai-agent.git
cd ai-agent

### Step 2 — Create virtual environment
python -m venv venv
venv\Scripts\activate

### Step 3 — Install dependencies
pip install streamlit requests

### Step 4 — Add your API Key
Open app.py and replace:
API_KEY = "your_api_key_here"
With your real Gemini API key from https://aistudio.google.com

### Step 5 — Run the app
python -m streamlit run app.py

## 🔑 Get API Key
1. Go to https://aistudio.google.com
2. Click "Get API Key"
3. Create a new key
4. Paste it in app.py
